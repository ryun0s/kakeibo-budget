Kakeibo — Household Budget Book is an offline yen ledger for recording purchases, setting monthly budgets, and seeing how household savings change over time. It opens with six months of sample entries and saves edits in your browser.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in your browser.
```
